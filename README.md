# ClipPoint — downloads oficiais

Página pública de apresentação, política de privacidade e instruções para baixar o ClipPoint, uma extensão Chrome da D6lab.

- Página: <https://codes4free.github.io/clippoint-download/>
- Releases: <https://github.com/codes4free/clippoint-download/releases>
- Privacidade: <https://codes4free.github.io/clippoint-download/privacidade.html>
- Instalação: <https://codes4free.github.io/clippoint-download/instalacao.html>

Este repositório contém somente o site estático e documentação de distribuição. Ele não contém os fontes da extensão nem o código do Worker. O ZIP compilado fica anexado a uma versão em GitHub Releases; os arquivos JavaScript executáveis do pacote podem ser inspecionados pelo usuário.

O ClipPoint é distribuído aqui para instalação manual no Chrome. Ele não está listado na Chrome Web Store e não recebe atualizações automáticas. Consulte as instruções e a política antes de instalar.

## Desenvolvimento local

Abra `index.html` em um navegador ou sirva esta pasta com um servidor estático. O site não depende de build, rastreadores ou chamadas de API.
