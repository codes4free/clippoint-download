# ClipPoint 0.0.5

Primeira versão pública para instalação manual.

- Resumo e pontos-chave com timestamps baseados em legendas nativas públicas do YouTube.
- Tendência opcional com amostra recente e limitada de comentários públicos.
- BYOK para OpenAI e Supadata; chave do YouTube opcional para a tendência.
- Instalação manual no Chrome; sem atualização automática.

O pacote não contém chaves de API. A análise requer configuração de chaves próprias. Consultas dos provedores podem consumir créditos ou quota conforme suas contas.
